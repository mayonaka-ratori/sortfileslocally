# PipelineAnalyst Skill

This skill specializes in debugging the media processing pipeline and identifying problematic files.

## Capabilities
- Parse `error.log` and `diag_output.log`.
- Correlate tracebacks with specific file paths.
- Suggest resolutions for common pipeline errors (e.g., corrupt files, OOM).

## Usage
Use this skill when processing fails or reports errors in the scan logs.
