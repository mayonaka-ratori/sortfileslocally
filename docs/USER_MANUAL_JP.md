# LocalCuratorPrime - ユーザーマニュアル

**LocalCuratorPrime** へようこそ！ このマニュアルでは、技術的な知識がなくても、本アプリをセットアップして使いこなす方法をわかりやすく解説します。

---

## 🏁 1. 初回セットアップ

1. **AIモデルのダウンロードを待つ**: 初回起動時、アプリはAIの「脳」となる複数のモデルをダウンロードします（合計約6GB）。安定したインターネット接続を確認してください。
   ![Setup Screen](C:/tools/organizefiles0112/LocalCuratorPrime/docs/mockup_hero.png)
2. **フォルダの設定**: サイドバーの「Settings（設定）」または「Setup（セットアップ）」タブを開きます。
   *注意: モデルの保存先ディレクトリを変更した後は、変更を反映させるためにアプリケーションを再起動してください。*
3. **ディレクトリの追加**: 「Add Folder（フォルダ追加）」をクリックし、画像や動画が保存されているパソコン上のフォルダを選択します。
4. **スキャンの開始**: 「Start Scan（スキャンの開始）」ボタンをクリックします。AIが各ファイルを解析し、説明文の作成や音声の文字起こしを開始します。

---

## 🔄 2. 基本的な流れ

1. **インデックス**: アプリがフォルダ内をスキャンします。
2. **検索**: 検索バーを使って、見つけたいものを探します。
   ![Search Interface](C:/tools/organizefiles0112/LocalCuratorPrime/docs/mockup_search.png)
3. **閲覧**: ギャラリーで画像を確認したり、タグで絞り込んだり、AIとチャットしたりします。
4. **整理**: 重複排除ツールを使って、不要なコピーファイルを削除します。

---

## 🛠 3. 機能ガイド

### 🔍 セマンティック検索
- **概要**: ファイル名ではなく、その「意味」や「内容」で画像を検索します。
- **メリット**: 「IMG_4829.jpg」のような名前を覚えていなくても、「雨の中の赤い車」と入力するだけで見つけられます。
- **使い方**: 画面上部の検索バーに説明を入力して、Enterキーを押してください。

### 🤖 自動AIタグ付け
- **概要**: AIが画像内のキャラクターやテーマ、作品名を自動で判別し、タグを付けます。
- **メリット**: 手作業で整理する手間がなくなり、コレクションを綺麗に保てます。
- **使い方**: スキャン中に自動で行われます。ギャラリーの画像の下にタグが表示されます。

### 🎬 動画内検索
- **概要**: 動画の「中の」特定の瞬間を検索します。
- **メリット**: 特定の言葉を話しているシーンや、特定のアクションが起きている場面をすぐに見つけられます。
- **使い方**: 通常の検索バーを使うだけです。結果には「Video @12.5s」のように再生時間が表示されます。

### 💬 ビジュアル・チャット
- **概要**: 画像についてAIに質問できるチャット機能です。
- **メリット**: 画像内の文字を翻訳したり、映っているものを詳しく特定したりできます。
- **使い方**: ギャラリーで画像をクリックして開き、右側の「Chat Panel」に質問を入力してください。

### 🚀 重複排除 (Deduplication)
- **概要**: 見た目が同じ、あるいはほぼ同じファイルを見つけ出します。
- **メリット**: 不要なコピーを削除して、ディスク容量を節約できます。
- **使い方**: 「Deduplication」タブに移動し、「Find Candidates（候補を探す）」をクリックします。

### 💾 メタデータの書き出し (EXIF/IPTC)
- **概要**: AIが生成したタグや説明文を、元のファイルに書き戻します。
- **メリット**: Adobe LightroomやWindowsのエクスプローラーなど、他のアプリでもAIが付けたタグを利用できるようになります。
- **使い方**: ファイル詳細画面で「Export Metadata」をクリックします。JPEGの場合は「In-place（直接書き換え）」、その他の形式は「XMP Sidecar」を選択してください。

## ❓ 4. よくある質問 (FAQ)

### 「最初のスキャンがとても遅いです。」
- **原因**: AIがGPU（グラフィックボード）やCPUを使って、ファイルを一生懸命解析しているためです。
- **解決策**: これは正常な動作です。一度スキャンが終われば、次からの検索は一瞬で完了します。

### 「'CUDA Out of Memory' エラーが出ます。」
- **原因**: グラフィックボードのメモリが不足しています。
- **解決策**: 他の重いアプリ（ゲームやブラウザなど）を閉じてから、再度スキャンを試してください。

### 「検索結果が何も出てきません。」
- **原因**: スキャンがまだ完了していないか、検索ワードが抽象的すぎる可能性があります。
- **解決策**: サイドバーのスキャン進捗を確認してください。別のキーワードでも試してみてください。

## 🛑 5. よくあるエラーメッセージ

| エラー内容 | 原因 | 解決策 |
|-------|-------|----------|
| `Path does not exist` | 選択したフォルダが移動または削除されています。 | 設定画面からフォルダを再度選択してください。 |
| `Model not downloaded` | 必要なAIモデルが見つかりません。 | セットアップ画面で、該当するモデルの「Download」をクリックしてください。 |
| `Scan already in progress` | すでにスキャンが実行中です。 | 現在のスキャンが終わるまで待つか、一時停止してください。 |
| `No resumable scan job found` | 再開できるスキャン履歴が見つかりません。 | 新しくスキャンを開始してください。 |
| `Original path no longer exists` | スキャン対象のフォルダが移動されています。 | フォルダを元の位置に戻すか、新しいパスでスキャンし直してください。 |
| `File not found` | ファイルが移動または削除されています。 | スキャンを再度実行してライブラリを更新してください。 |
| `Invalid image file` | ファイルが破損しているか、非対応の形式です。 | 他のアプリでそのファイルが開けるか確認してください。 |
| `Network Error` | サーバーが起動していません。 | 黒いターミナル画面（Python）が開いているか確認してください。 |
| `Access denied: file not in library` | 登録されていないファイルを削除しようとしました。 | アプリが認識（スキャン）済みのファイルのみ管理可能です。 |
